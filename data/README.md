# Данные

- Исходные Parquet-файлы и словарь остаются в `../Dataset/`, чтобы не
  перемещать и не дублировать крупный полный датасет.
- `prepare_data.py` читает sample Parquet по умолчанию и записывает полный
  очищенный Parquet и CSV, компактную таблицу Tableau, агрегаты и профиль
  колонок в `processed/`.
- `python prepare_data.py --full` явно переключает чтение на полный Parquet.

В CSV используется разделитель `;` и кодировка UTF-8 с BOM: это помогает
русской версии Excel открыть данные по колонкам. При подключении в Tableau
выбирайте разделитель `Semicolon/Точка с запятой`. В CSV заголовок находится
в первой строке; каждая следующая строка — отдельная карточка.

- `incidents_clean.csv` — вся подготовленная широкая таблица. Подойдет для
  изучения в табличном редакторе, но для первого Tableau-дашборда лучше
  использовать компактный `tableau_incidents.csv`.
- `tableau_incidents.csv` — одна строка на карточку, только выбранные поля
  для графиков и фильтров.
- `tableau_verdict_daily.csv` — готовый подсчет карточек по дате и вердикту.
- `tableau_source_summary.csv` — готовый подсчет карточек по источнику и
  вердикту. В обоих агрегатах `card_count` означает число карточек.
- `column_profile.csv` — справочник типов, пропусков и значений полей; это
  описание схемы, а не данные карточек для основного дашборда.

Пропуски остаются пропусками, а бинарная target-метка неизвестных вердиктов
не заполняется. Словарь и оговорки приведены в
`../docs/data_overview.md`.
