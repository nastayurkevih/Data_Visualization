# Исследовательский анализ данных SOC: банк вопросов

**Датасет:** `iavd_incidents_raw_target.parquet` — 240 295 карточек инцидентов × 97 полей.
**Треки:** BI-аналитика (Qlik Sense) и ML-инжиниринг (Python/Pandas).
**Пояснения:** Каждая команда отвечает на вопросы своего варианта; контрольные числа — в конце файла. Полные примеры («как отвечать») — в начале каждого блока.

**Материалы:** `iavd_incidents_raw_field_dictionary.md` (описание полей, IGNORE/REPLACE), раздел «Структура мультизначных полей» (разделители `~~||~~` и `|`).

## Как работать

- **Qlik Sense**: parquet загружается через Qlik DataTransfer / коннектор к папке. Инструменты: «Таблица», «Фильтр», Bar chart, выражения `Count()`, `Count(distinct ...)`, Set Analysis `Count({<Вердикт={'False Positive'}>} EntityId)`, `SubField(значение, '~~||~~')`, `SubField(пара, '|')`.
- **Python**: `pd.read_parquet()`; инструменты: `value_counts()`, `nunique()`, `groupby().agg()`, `str.split(...).explode()`, `pd.to_datetime()`.
- **Контрольные числа** — в конце файла; ответ верен при совпадении числа и порядка. Главное — не только число, но и **инсайт**: формулировка наблюдения о данных.

## Блок 7. Мост к ML

### Полный пример

**Вопрос.** Насколько сбалансирован целевой класс (FP) и какие признаки-«утечки» исключить?
**Python:**
```python
df["y"] = (df["Вердикт"] == "False Positive").astype(int)
print(df["y"].mean())                                # 0.627
leak = df["Решение"].fillna("").str.contains("FP", case=False)
print((leak & (df["y"]==1)).mean())                  # 0.009
```
**Qlik Sense:** KPI доля FP; таблица связи категорий с таргетом.
**Инсайт:** дисбаланс 63/37 умеренный; таргет — из `Вердикт` (FP vs остальные) или из флага `Ложное срабатывание` — они не идентичны (см. 2.10), выбор таргета — проектное решение. Свободные тексты (`Решение`, `Комментарий`) могут раскрывать исход — риск утечки.
