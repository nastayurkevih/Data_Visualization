# SOC incident triage — учебный проект IAVD

Прототип включает BI- и ML-треки на одних подготовленных данных:

- **Tableau:** плоский факт на карточку и два готовых агрегата в
  `data/processed/`.
- **Taipy:** таблица, интерактивный Plotly-график, асинхронные callbacks
  инференса и SHAP в `ml_taipy/`.
- **EDA:** сводка схемы, пропусков, типов и классов цели для обеих команд.

## Быстрый старт

Требуется Python 3.11–3.13. Сначала создайте данные на 1 000 строках:

```powershell
python data/prepare_data.py
python eda/quick_eda.py
```

По умолчанию используется быстрый семпл. Полный датасет (~174 МБ) выбирается
явно: `python data/prepare_data.py --full`. Для запуска Taipy установите
`requirements.txt`, положите совместимую обученную модель в
`ml_taipy/models/incident_classifier.joblib` и выполните
`python ml_taipy/app.py`.

## Структура

```text
Dataset/                 исходные файлы, предоставленные курсу
data/prepare_data.py     очистка и экспорт
data/processed/          Parquet, CSV для Excel/Tableau и профиль всех колонок
eda/                     общий краткий EDA
bi_tableau/              подсказки по BI-выгрузкам и дашборду
ml_taipy/                GUI, модельный интерфейс и async/SHAP callbacks
docs/                    разбор датасета и нарратив для защиты
tests/                   проверки подготовки данных
```

Исходники намеренно остаются в `Dataset/`: 174-МБ файл не перемещается и не
копируется в `data/`. Скрипт указывает на исходную папку и записывает
промежуточные результаты в `data/processed/`. CSV используют `;` как
разделитель для корректного открытия по колонкам в русской версии Excel;
при импорте в Tableau укажите `Semicolon / Точка с запятой`.

## Важное для интерпретации

В выборке 79,3% исходов имеют значение «Не указан». Они не считаются
отрицательным классом в `binary_target`; модель обучается только на явно
размеченных результатах. Подробнее — [разбор данных](docs/data_overview.md).
