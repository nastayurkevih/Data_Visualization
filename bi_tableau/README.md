# BI-трек: Tableau

После `python data/prepare_data.py` подключите Tableau к CSV в
`data/processed/`:

- `tableau_incidents.csv` — плоская строка на карточку, без ФИО и текстов
  решений; подойдет для фильтров и детального обзора.
- `tableau_verdict_daily.csv` — число карточек по дате создания и вердикту;
  подходит для линейного тренда.
- `tableau_source_summary.csv` — число карточек по источнику и вердикту;
  подходит для сравнения источников.
- `incidents_clean.csv` — полный экспорт обработанной таблицы со всеми
  исходными колонками, календарными полями и `binary_target`. Таблица широкая
  и содержит технические/служебные поля; для первого дашборда используйте
  более компактный `tableau_incidents.csv`.

CSV используют разделитель `;` и UTF-8 BOM. При подключении текстового
файла в Tableau укажите `Semicolon / Точка с запятой` в настройке разделителя.
Если таблица показалась одной колонкой, почти всегда Tableau использует
неверный разделитель: выберите `;`, и имена полей появятся отдельными
колонками. Заголовок находится в первой строке, каждая следующая строка —
отдельная карточка.

Что посчитано в агрегатах:

- `tableau_verdict_daily.csv`: на каждую комбинацию даты и вердикта посчитано
  число уникальных карточек. `card_count` — число карточек, не число
  исходных алертов внутри них.
- `tableau_source_summary.csv`: на каждую комбинацию источника и вердикта
  посчитано число уникальных карточек; смысл `card_count` тот же.
- В `tableau_incidents.csv` одна строка — одна карточка. Поле
  `incident_count` — число исходных инцидентов, собранных в эту карточку.

В исходном семпле целевой вердикт сильно смещен в сторону «Не указан».
Показывайте его отдельной категорией и не называйте эту категорию «угрозой»:
вердикт описывает решение по карточке, а не подтвержденный ground truth. Для
доли FP используйте явный вердикт `False Positive`, а знаменатель и фильтры
указывайте в подписи визуализации.

## Макет диаграмм для ручного повторения в Tableau

Откройте `tableau_dashboard_guide.svg` в браузере: это макет по текущему
`tableau_incidents.csv` с четырьмя диаграммами и подсказками под каждой —
какие поля перетащить на строки, столбцы, цвет, угол и метку. Это картинка
для повторения вручную, а не Tableau-книга и не подключаемый дашборд.

Макет можно пересобрать после обновления данных командой
`python bi_tableau/create_dashboard_guide.py`. Скрипт использует только
стандартную библиотеку Python и сохраняет SVG рядом с собой.

Для первого дашборда подходят распределение вердиктов, динамика карточек по
датам и сравнения по источникам и критичности. Временной ряд показывает
динамику нагрузки, а столбцы удобны для сравнения категорий; сырые
мультизначные поля не разворачиваются, чтобы не размножать карточки и не
искажать счетчики.
